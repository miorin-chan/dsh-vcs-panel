# dsh-vcs-panel

[English](README.md) | 中文

DeepSeek Harness 右侧栏里的版本管理插件。
在右侧栏新增 `版本管理` 页签（其他语言为 `VCS`），支持 **Git** 与 **Jujutsu** 仓库的工作区改动、语法高亮 diff，
以及带 lane 图的提交历史，并可在同一处完成 Git 分支、远程分支、标签与提交操作：检出、重命名、删除、
合并到当前分支、把当前分支变基到另一分支、推送分支、检出或删除远程分支、把远程分支合并或拉取到当前分支、
删除或推送标签，在提交上创建标签或分支、检出提交、拣选、还原、丢弃、合并、变基或重置，或与上游同步。

## 功能概览

- **住在右侧栏。** 版本管理与文件、终端等页签并列，右侧栏引导页也提供入口；轮末横幅与快捷键打开同一个页签。
  顶部栏开关让时间线与改动并排，或一次只显示一栏，宽栏也能把整宽留给 diff。
- **时间线与 lane 图。** 在同一处查看工作区改动和按拓扑顺序排列的提交历史，浏览分支、书签和标签。
  仓库菜单顶栏可以切换「全部」或「仅所选」。点击仓库行可将其纳入或移出「仅所选」。
  左侧时间线中的仓库分组可以独立展开或收起。选中组内条目时，详情与顶部操作切到该仓库。
  顶栏右端的齿轮打开「管理仓库」，可预览并添加扫描目录，或登记单个嵌套仓库；
  同时含 `.git` 与 `.jj` 的仓库可在这里选择 Git 或 Jujutsu 读取。
  发现规则用相对路径保存在会话目录的 `.dsh/vcs-panel.json` 中。
- **同图查看工作树。** 在「工作树」菜单勾选 Git 工作树或 Jujutsu 工作区，并在菜单顶部标题行切换「提交」范围：
  **全部**（默认）或**仅所选**；单工作树 Git 的分支菜单顶部也同步提供同款 **全部** / **仅 HEAD** 开关。
  收窄范围时，顶部栏会在分支按钮（单工作树 Git）或工作树按钮（多工作树 / Jujutsu）内侧显示紧凑的筛选图标。
  默认勾选会话工作树。Git 在图上为所选树显示独立改动行，Jujutsu 以 `名称@` 标记所选的工作副本提交。
  勾选不改变会话目录或检出状态。
- **创建与移除。** 在工作树菜单顶栏点「+ 新建」，使用 `../topic` 这样的路径在当前仓库旁创建工作副本。
  Git 可新建分支、检出空闲的本地分支或使用分离 `HEAD`，Jujutsu 可从指定父修订创建工作区。
  通过行末「⋯」可移除符合条件的 Git 工作树并保留分支。
  Jujutsu 可解除工作区关联并保留工作文件（共置的 Git 工作树会一并解除关联），
  也可在支持 `jj workspace remove` 的版本上删除其目录。
- **内联变更树。** 收起时作为可折叠文件列表浏览，展开任一文件即可在原位阅读 diff，支持文件头吸顶、
  单栏或左右对比、自动换行（默认开启）。
- **贴合 Git 与 Jujutsu 模型。** Git 显示已暂存 / 未暂存分组（未跟踪项标为 `U`，
  新增加入项标为 `A`）与 ahead/behind；面板可见时跟随 Git 本地变更，分别更新工作区状态和历史。
  Jujutsu 显示变更 ID 与书签。在外部编辑文件后，可点「刷新」为勾选的工作区做快照。
- **Git 暂存。** 指针悬停或聚焦一行时，左缘的暂存列显示该行的命令：「未暂存」组的行显示 `+`（暂存），
  「已暂存」组的行显示 `−`（取消暂存）。
  半填充的圆点标出在两组都有改动的文件；在「未暂存」组执行会暂存剩余改动，在「已暂存」组执行会取消该文件的全部暂存。
  目录与分组行一次暂存或取消暂存其下全部文件（包括未跟踪目录），一次撤销即可还原。
  按 `s` 暂存、`u` 取消暂存光标所在的行。
  展开支持逐行暂存的文本 diff，在单栏或左右对比中点击增删行前的复选框，即可直接暂存或取消暂存该行；
  点击 hunk 标题前的复选框可一次处理该改动块，部分暂存时点击短横杠会暂存块内剩余改动。
  操作仅在单选仓库默认 Git 工作树时可用，只修改 Git index，保留工作文件内容。
  工作树详情工具栏的列表图标可在默认的合并视图与分组视图之间切换。
  合并视图每个文件只显示一次，文件与目录显示复选框：空框表示未暂存，勾号表示已暂存，短横杠表示部分暂存；
  点击短横杠可暂存剩余改动，文件的 **…** 菜单可取消全部暂存。
- **撤销和重做暂存操作。** 工作区详情工具栏的弯箭头可撤销或重做面板发起的整文件和选行暂存、取消暂存。
  悬停或用键盘聚焦可查看将处理的文件和范围。
  若目标索引条目或 `HEAD` 已发生变化，面板会保留当前改动并提示。
  撤销后执行新的暂存操作会清除重做历史。
  历史在 DSH 重启时清空。
- **轮末横幅与全局快捷键。** 有文件改动的对话轮次末尾显示紧凑的版本管理横幅（展示该轮所在的分支或 `@`、
  本轮改动文件数与 `+` / `−` 行数统计），替代对话自带的改动文件卡片；
  在任意视图按 `⌘⇧G` / `Ctrl+Shift+G` 打开右侧栏页签，再按一次滑回对话。
- **一键同步。** Git 分支旁的按钮显示 ahead/behind 计数；点击后抓取上游，再快进或推送。
  分支已分叉、快进会覆盖本地改动或分支没有上游时不做改动，并提示下一步怎么做。
- **切换分支。** 分支名本身是菜单：展开仓库的本地分支，选中即检出。
  菜单只列本地分支，不隐式创建远程分支的本地副本；远程分支需要从提交历史里的徽标显式检出。
  会覆盖本地改动时 Git 拒绝，面板不贮藏、不丢弃、不强制。
- **分支操作。** 右键当前分支、列表中的任一分支、提交历史里的分支徽标，
  或在详情头部点击/键盘激活分支徽标（也可在分支控件上按 `Shift+F10`），可检出、
  重命名、删除、合并到当前分支、把当前分支变基到它、推送。
  当前分支只提供重命名与推送（当前分支未配置上游时，“推送分支”保留在菜单并置为禁用并说明原因）。
  重命名、删除、合并、变基在运行前说明将发生什么；删除未合并的分支需要再次明确确认；
  合并或变基冲突会自动中止，分支保持不变。
  推送只把指定的分支送到它配置的上游，从不强制推送。
- **远程分支操作。** 右键历史里或详情头部激活 `origin/topic` 这类远程分支徽标，
  可检出、删除远程分支、合并到当前分支、拉取到当前分支。
  检出会询问本地分支名，创建一个跟踪该远程的本地分支并检出；删除先确认，再移除远程上的分支并清掉过期的跟踪引用；
  合并与拉取沿用本地合并的冲突中止规则，拉取会先抓取指定远程分支再合并。
  分离头指针时不提供合并与拉取。
- **标签操作。** 右键提交历史里的标签徽标，或在详情头部点击/键盘激活标签徽标，可打开“删除标签…”与“推送标签…”。
  删除只移除本地标签，并在确认框里说明远程副本仍会保留；推送只把该标签送到选定的已配置远程，
  从不强制，因此远程已有不同对象时会被拒绝而不是被覆盖。
  推送对话框会加载仓库的远程列表，没有远程时也会说明。
- **提交操作。** 右键提交行（或聚焦后按 `Shift+F10`），可添加标签、创建分支（可选创建后立即检出）、检出、
  拣选、还原、丢弃、合并到当前分支、把当前分支变基到此提交，或把当前分支重置到此提交。
  所有历史写操作都先打开对话框，写明目标提交与将发生的变化；发生冲突时会中止并恢复分支。
  菜单按已加载历史中的祖先位置自动裁剪不适用动作，丢弃再由服务端确认它位于当前分支；
  重置可选择 Soft、Mixed 或 Hard，只有 Hard 会丢弃已暂存与未暂存的改动。
  时间线行超过 3 个引用时折叠提示为 `+N`，详情头部继续列出全部可操作引用徽标。
- **写入都需明确操作。** 写入由工作树、暂存、取消暂存、同步、分支、远程分支、标签或提交操作发起。
  冲突的合并、拉取、拣选、还原、丢弃或变基会自动中止，推送与远程删除都不强制。
  Jujutsu 在手动刷新或有改动的 Agent 回合结束后快照工作副本。
  跟随 DSH 主题与全部 8 种界面语言，大历史与大 diff 按需加载。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| `⌘⇧G` / `Ctrl+Shift+G` | 在右侧栏打开 `版本管理` 页签；页签正在显示时收起右侧栏（可在 **Settings → Shortcuts** 重绑定） |
| `↑` `↓` 或 `j` `k` | 沿时间线提交，或变更树行与展开文件 hunk header 的同一条纵向列表移动（在顶端第 0 行继续上移回到提交头部） |
| `s` / `u` | 在 Git 工作树中暂存或取消暂存光标所在的文件、目录或分组 |
| `Tab`、`↑` `↓`、`Space` | 用 `Tab` 聚焦 diff 中的暂存复选框，用 `↑` / `↓` 在 diff 的复选框间移动，按 `Space` 暂存或取消暂存。 |
| `PageUp` `PageDown`、`Home` `End` | 在时间线或变更树中按视口翻页，或跳到首尾 |
| `←` `→` 或 `h` `l` | 进入变更树、展开行或进入已展开文件的首个 hunk；`←` / `h` 先收起展开的文件，再按才返回时间线 |
| `Enter`、`Space`、`Esc` | 折叠/展开当前行或激活详情头部的引用徽标；`Esc` 返回时间线 |
| `↑` `↓`、`Home` `End` | 在展开的仓库、工作树、分支或操作菜单内移动；`Esc` 关闭菜单 |
| 右键 / `Shift+F10` | 右键或详情头部激活分支、远程分支或标签徽标打开对应操作；在分支控件上按 `Shift+F10` 打开分支操作，在提交行上按 `Shift+F10` 打开提交操作 |
| `Enter`、`Esc` | 确认或取消分支、远程分支、标签或提交操作对话框 |
| `[` / `]` | 在变更树中移动到上一行 / 下一行，跳过 hunk header |

点击顶部或详情工具栏按钮，或切换回当前窗口时，面板会保持并自动准备就绪到当前活动的导航停靠点，
且不打断输入框或外部对话框。

## 安装

需要 **DSH 0.2.2-rc.3+**（Desktop 或 Web，包含右侧栏页签与导航 API），且 `PATH` 中包含 `git` 或 `jj`。
发现和管理同仓库的其他 Jujutsu 工作区需要 **jj 0.47+**，且工作区路径已登记；否则仍能查看当前工作区。

- **界面安装：** 打开 **Plugins → Add plugin**，选择本目录后重启 DSH。
- **命令行安装：**
  ```sh
  dsh plugin --profile desktop add link:/path/to/dsh-vcs-panel
  ```
添加后重启 DSH。可随时在 **Plugins** 中停用或卸载（卸载后恢复对话默认的改动文件卡片）。

## 开发

```sh
npm install          # 安装构建与类型依赖
npm run build        # 从 src/ 构建 index.js、client.js 与 lib/
npm run typecheck    # 运行 tsc -p tsconfig.json
npm run check        # 测试、类型、产物新鲜度与类型包版本
npm pack --dry-run   # 检查打包内容
```

源码是 `src/` 下的 TypeScript：`src/host/` 为宿主半，`src/lib/` 为私有宿主模块，`src/client/` 为浏览器半。
`index.js`、`client.js` 与 `lib/**/*.js` 是由这些源码构建的入库产物，修改源码后运行 `npm run build` 更新。
类型只以 `import type` 使用，产物里没有 `@deepseek-ai/*` 的运行时 import。
验证 `dsh plugin` 安装、升级与卸载时请使用临时 `DSH_HOME`，保持真实 profile 独立。
在运行中的 DSH Web 里检查面板时，用 `node scripts/fixture.mjs <dir>` 生成 Git 夹具，
再按 [`TODO.md`](TODO.md) 的步骤启动。
